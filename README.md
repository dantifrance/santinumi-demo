# Santinumi — sito dimostrativo

Sito statico senza build né dipendenze, pronto per GitHub Pages o Cloudflare Pages.

## Pubblicazione con GitHub Pages
1. Crea un nuovo repository GitHub pubblico, ad esempio `santinumi-demo`.
2. Carica `index.html`, `styles.css`, `script.js` nella radice del repository.
3. Apri **Settings → Pages** e scegli **Deploy from a branch**, **main**, **/(root)**; salva.
4. Dopo la pubblicazione il sito sarà su `https://USERNAME.github.io/santinumi-demo/`.

## Attenzione prima di lanciarlo
- Le fotografie sono immagini dimostrative esterne da Unsplash, non le immagini originali Santinumi.
- Il simbolo ✺ è un segnaposto grafico, NON il logo originale con damigiana.
- Il link di contatto `info@example.com` è fittizio.
- La storia del brand, i prodotti e i testi educativi devono essere revisionati.
- Inserire privacy policy, dati aziendali, informazioni su allergeni/prodotti e tutti i requisiti applicabili prima della messa online ufficiale.
